# ShrinkDrop website

This repository contains the static marketing site only. ShrinkDrop's Electron app source remains in its separate private repository.

The site is plain HTML, CSS, and JavaScript. GitHub Pages publishes it for free using the workflow in `.github/workflows/pages.yml`.

## Payment plan

- One macOS product with a one-time price of CA$5 or US$5, based on checkout currency.
- No recurring subscription.
- Dodo Payments hosted checkout as Merchant of Record.
- Dodo license-key entitlement for purchase emails and app activation.

The app now requires a Dodo activation key before compressing images. Keep checkout disabled until the Dodo product links are configured and the public DMG is signed and notarized. See `PAYMENTS.md` for the setup flow. Do not add payment API keys or app source to this repository.
